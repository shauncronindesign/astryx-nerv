# References

Frames from the Rebuild films, chosen from a scan of 252 Blu-ray frames
plus the Misc and Wallpaper sets. Only frames that show a user interface
are included. Each file is named `<component>-<frame number>.jpg`; the
number matches "Evangelion Rebuild - Blu Ray N.png" in the source folder.
The component names match the inventory in the "Rebuild UI reference"
section.

Use these for reference only, to check a component against its source
before you build it. They aren't for shipping, and they keep this system
private.
